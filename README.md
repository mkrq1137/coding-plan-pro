## 90,000 次请求够用吗：一次提问不等于一次请求

这是最多人算错的一笔账。官方按“模型调用次数”扣减额度，你在 Claude Code 里提一个问题，背后可能是模型被调用了多次：简单任务大约消耗 5–10 次调用，复杂任务 10–30 次甚至更多，实际消耗取决于任务难度、上下文长度和工具使用情况。按这个区间折算，每月 90,000 次请求大致对应几千到一万多次简单交互；让智能体自主跑长任务、频繁读写文件的话，消耗会明显更快。

三重上限同时生效，任何一个先触顶就暂停调用：

- 每 5 小时最多 6,000 次
- 每周最多 45,000 次（每周一 0 点重置）
- 每月最多 90,000 次（订阅日重置）

这三个数字是相互独立的上限，互不叠加，哪个先到就在哪里暂停。5 小时额度是滚动恢复的：每分钟释放你 5 小时前用掉的部分——10:00 用了 100 次，15:00 就恢复 100 次；10:30 用的 50 次，15:30 恢复。这个机制比“每天固定额度”灵活，但短时间高强度爆发照样会被限流，没法把一周的量攒到周一冲完。正常交互式编程，6,000 次/5 小时相当宽裕；多项目并行跑 OpenClaw 这类自主智能体时，才需要盯着控制台的用量页面精打细算。

## 订阅前必须知道的三条限制

不支持退款、禁止 API 形式调用、账号专享——三条都写在官方条款里，违反的代价不小：

1. **不支持退款**。不确定自己用量能不能吃满额度的话，先按量付费试一两个月再订。
2. **禁止 API 调用形式的用法**。只能在编程工具里交互式使用；拿去跑自动化脚本、给自建应用当后端、批量调用都属于违规，可能导致订阅暂停或 Key 被封。
3. **账号专享**。套餐只给订阅本人用，共享账号可能导致权益受限。

还有两点信息来自第三方测评，官方页面写得不显眼：一是模型名单可能调整，前面已经提过；二是有测评指出服务协议中包含模型输入和输出可能用于改进服务的条款，介意代码数据被这么使用的用户需要自己权衡。

固定额度也有一个常被忽略的好处。跑 OpenClaw 这类自主智能体时，指令越模糊、任务越开放，消耗波动越大，按量付费模式下出过用户被烧掉数万元账单的案例；固定月费把最坏情况锁死在“额度提前用完”，损失有上限。对新手来说，这比先用后付的模式友好得多。

## 什么人适合订，什么人不必

判断标准就一条：你现在每月在 AI 编程上的真实开销。

适合订的情况：

- 每月 API 花费稳定超过 200 元的重度用户，订阅基本稳赚

- 准备让智能体自主跑任务、担心按量计费失控的人

不必订的情况：

- 轻度用户。偶尔补全代码、改改小 bug，每月请求量可能连几千次都用不到，按量付费更划算
- 必须用白名单之外模型的人，比如固定依赖某个 Claude 或 GPT 模型的工作流
- 想做批量 API 自动化的场景——这个用法本身就被条款禁止

放在同类产品里对比会更清楚：智谱的 GLM Coding Plan 年初就试行限量发售，每日销量一度降到原来的两成；Kimi 则把订阅从按请求计费改成了按 Token 计费。百炼这套“一次订阅、四家模型随便切”的打包方式，在国产模型订阅里覆盖面算是最宽的一档，价格不算最低，但省去了多平台来回切换的管理成本。

## 常见问题

**订阅后为什么还在扣费？**
大概率是用了按量付费的通用 Key（`sk-` 开头），而不是套餐专属 Key（`sk-sp-` 开头）。换成专属 Key 和 `coding.dashscope.aliyuncs.com` 域名下的 Base URL，就会正常从套餐额度扣减。

**Lite 基础版还能用吗？**
已购用户可以用到套餐到期，但 4 月 13 日起已无法续费和升级，到期后想继续只能订 Pro。

**能退款吗？**
不能，条款写明不支持退款。

**为什么经常显示无货？**
名额有限、先到先得，每天早上 9:30 补充名额，抢不到第二天再试。

**每月 90,000 次请求大概能用多久？**
取决于任务复杂度。简单交互每次消耗 5–10 次调用，重度智能体工作流单次任务可能吃掉 30 次以上。先用按量付费观察两周真实消耗，是最稳妥的估算方式。
